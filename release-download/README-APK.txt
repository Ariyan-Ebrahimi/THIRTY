THIRTY Android test APK
=======================

APK included: THIRTY-debug.apk

This is a debug build intended for initial testing, not a signed production release.
To install, transfer the APK to an Android phone and open it. If prompted, allow
installation from that source. Only install APKs you trust.

For GitHub distribution, upload this APK to the repository's Releases section.
Do not commit generated APKs into the source tree unless you intentionally want to.
